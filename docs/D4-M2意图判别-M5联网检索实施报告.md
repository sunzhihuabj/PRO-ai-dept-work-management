## 三、已知问题与后续

1. **Bing 结果相关性差**：cn.bing.com 对程序化请求（无 Cookie 会话）返回相关度偏低的商业化结果。D5 可评估：加结果相关性过滤（关键词重合度阈值）或接入可配置搜索 API（用户申请 Key 后配通道）。
2. **客户字典为空**：`mdm_customer` 当前无数据，客户名脱敏由单测覆盖（mock 字典 8 例全过）；主数据录入后字典 5 分钟内自动生效。
3. 意图捞回实测触发率低（规则路由+tryOps 内部 LLM 兜底覆盖率高）——符合成本预算设计，捞回层保证语义盲区兜底。
4. DuckDuckGo Lite 备源在本网络环境不可达（Bing 主源可达，备源为容灾冗余）。
