## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| Docker Desktop 卡 Starting... | WSL 未生效（未重启）；`wsl --update` 后重启 |
| 镜像拉取超时 | 检查 registry-mirrors 配置；`docker compose pull` 重试 |
| Dify 打不开 /install | `docker compose ps` 看 api/worker 是否 Healthy；`docker compose logs api` |
| Dify 连不上 MCP | URL 必须为 `host.docker.internal:8081`；防火墙放行 8081 |
| Hermes 拉取失败 | 换 `-i https://mirrors.aliyun.com/pypi/simple/` |
| MCP 401 | X-API-Key 与 `app.mcp.api-key` 不一致 |
