## 三、自主决策与偏差披露（无人值守模式下按规划红线补齐）

1. **本机无 RabbitMQ/Redis/pgvector/Flowable/Docker 环境**：事件总线以本地事件表等效（轮询+指数退避+死信），任务队列为 DB 轮询+乐观锁，向量存储为 MySQL+内存余弦，审批流为状态机表。四者均已预留标准切换接口，环境就绪后配置切换。
2. **AGT-11 BOM 13 条规则**：V2 详细规则文档缺失，自主制定（R01~R13，编码/数量/单位/重复/关键件覆盖/螺栓等级/钢板材质/防腐等），纯确定性引擎不经 LLM 保证可复现；业务方确认后可增删。
3. **AGT-06/07 文本来源**：知识库文档（documentId）与台账字段合成（contractId）双通道；扫描件 OCR 预留 PaddleOCR。
4. **Mock 通道契约感知**：网关在声明 JSON 契约时把 schema 随首调 prompt 下发（真实通道同样受益）；MockProvider 按 required 字段返回确定性 JSON，使结构化能力在零费用下全链路可测。
5. **AGT-08 通知对象**：Phase 1 简化为领导账号（1L），Phase 2 权限域完善后按财务/领导角色查询。
6. **真实文档基线（规划第 3 周 20 份）**：用户尚未提供真实合同/方案样张，本报告以生成样例文档完成功能基线；真实文档到达后按 T-118 口径补测准确率（建议届时配置 DEEPSEEK 等真实通道再测——冒烟中已验证假 Key 401 会正确走重试→降级链转人工）。
