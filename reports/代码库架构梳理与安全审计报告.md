### 1.3 核心业务流

1. **认证**：账密登录（BCrypt 比对）→ 签发 2 小时 HS256 JWT → 前端存 localStorage / 小程序存 storage → 请求头 `Bearer` 注入 → `JwtAuthenticationFilter` 解析 → `SecurityConfig` 仅要求"已认证"。
2. **项目管理**：Project → Phase → Task → WorkHour → DeliverableChecklist（阶段门 Gate 控制流转）。
3. **文件链路**：上传（本地磁盘 `D:/dept-mgmt/files/<projectId>/...`）→ file_info + file_version 双写 → 审核（角色校验）→ 归档 + archive_record 台账。
4. **绩效/精益**：KPI 指标 → 权重 → 评分计算/发布；精益工具（A3、浪费记录、价值流、根因分析、经验教训）。
5. **AI**：Ollama 日报/周报摘要 + 文件版本差异分析（读磁盘文本文件拼 prompt）。
6. **审计**：`@OperLog` 注解 → AOP 异步落库 sys_oper_log。

## 三、高危问题详情（🔴）

### H1. 全系统缺失接口级权限控制（垂直越权 + 水平越权）

- **位置**：整个 controller 与 service 层。全代码库唯一一次角色校验在 [FileAuditService.java:31](file:///d:/2、开发源码/基于AI的部门工作管理软件0812/backend/src/main/java/com/dept/mgmt/service/FileAuditService.java#L31)（`ROLE_ARCHIVIST/ROLE_AUDITOR/ROLE_DEPT_LEADER`）；未发现任何 `@PreAuthorize` / `hasRole` 检查（全局 grep 仅此 1 处命中）。
- **证据**：[SecurityConfig.java:64-67](file:///d:/2、开发源码/基于AI的部门工作管理软件0812/backend/src/main/java/com/dept/mgmt/security/SecurityConfig.java#L64-L67) 只配置了 `anyRequest().authenticated()`，即**只要登录，任何接口都能调**。
- **典型可越权点**（均已逐一验证）：
  - 用户增删改、重置密码、启停用：[UserController.java:68-120](file:///d:/2、开发源码/基于AI的部门工作管理软件0812/backend/src/main/java/com/dept/mgmt/controller/UserController.java#L68-L120)
  - 项目创建/更新/删除（无成员归属校验）：[ProjectService.java:157-188](file:///d:/2、开发源码/基于AI的部门工作管理软件0812/backend/src/main/java/com/dept/mgmt/service/ProjectService.java#L157-L188)

  - 奖金管理 BonusService、精益工具 LeanService、通知 NoticeService、部门 SysDeptService 等全部写接口
- **风险等级**：🔴 高（本项目最严重问题）
- **影响**：普通技术员（ROLE_TECHNICIAN/ROLE_DEVELOPER）可删除项目、改 KPI 权重、发奖金、改他人数据；数据层面（水平越权）同样无归属过滤。
- **修复建议**：
  1. 在 `SecurityConfig` 启用方法级安全（`@EnableMethodSecurity`），按角色对管理类接口加 `@PreAuthorize("hasRole('DEPT_LEADER')")`；
  2. 定义角色-接口矩阵（种子数据 sys_menu.perms 已有 `system:user:list` 等权限串但后端从未使用，应落地校验）；
  3. 业务层补数据归属校验：项目负责人/成员才能改项目、任务经办人才能改任务。

### H5. JWT 密钥硬编码可预测 + 无 Token 撤销机制

- **位置**：[application.yml:52](file:///d:/2、开发源码/基于AI的部门工作管理软件0812/backend/src/main/resources/application.yml#L52)；[JwtUtils.java:38-41](file:///d:/2、开发源码/基于AI的部门工作管理软件0812/backend/src/main/java/com/dept/mgmt/security/JwtUtils.java#L38-L41)；[JwtUtils.java:120-128](file:///d:/2、开发源码/基于AI的部门工作管理软件0812/backend/src/main/java/com/dept/mgmt/security/JwtUtils.java#L120-L128)

secret: ZGVwdC1tZ210LWp3dC1zZWNyZXQta2V5LWFpLWRlcHQtbWFuYWdlLWZpcmUtMjAyNg==

### H6. 文件上传文件名未净化 → 路径穿越写入

- **位置**：[FileService.java:68-108](file:///d:/2、开发源码/基于AI的部门工作管理软件0812/backend/src/main/java/com/dept/mgmt/service/FileService.java#L68-L108)
