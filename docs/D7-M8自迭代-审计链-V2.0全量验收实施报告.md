## 一、交付范围

### M8 自迭代闭环

**数据库**（database/16_self_iteration_audit.sql）
- `agent_feedback`：run/message/task 三源 ±1 评分 + 维度归因（ACCURACY/SPEED/SAFETY/TOOL）
- `soul_patch_proposal`：周归因建议（period/category=SOUL_PATCH/TOOL_REQUEST/SKILL_TEMPLATE/root_cause/status）
- `soul_change_log`：SOUL.md 版本链（version/change_type/content_snapshot，唯一版本号）
- `skill_template`：任务书模板库（use_count/success_count/success_rate/last_used_at）
- `hermes_regression_suite`：30 条黄金指令（25 路由断言 G01-G25 + 5 越权断言 P01-P05）+ 最近结果回写

**后端**
- `SelfIterationService`：反馈提交（TASK 差评即时归因）/ 统计 / `weeklyIterate()`（@Scheduled 周一 08:00 + 手动补跑；本周差评+失败/升级任务 → 本地规则归因（TASK_UNCLEAR/TOOL_MISSING/KNOWLEDGE_GAP）→ 建议落库（同周期同归因幂等）→ SCENE_SELF_ITERATION 决策建议通知）
- `SoulManageService`：采纳补丁 → 追加 SOUL.md「部门口径补丁」段 → soul_change_log 快照落版本链 → **回归门槛（通过率 <0.90 拒绝写入）**；版本回滚（回滚本身也是版本记录）
- `SkillTemplateService`（独立服务避免 HermesDelegate→SelfIteration→AiChat→HermesDelegate 循环依赖）：委托终态计数沉淀（指令前缀 24 字聚合，成功率=success/use）
- `RegressionSuiteService`：`dryRoute` 纯判定回归（零 LLM 成本）→ PASS/FAIL/SKIP 计分 + 通过率（分母=实际断言用例）+ 越权结果回写
- `AiChatService.dryRoute(content)`：与 routeAndReply 规则层同源的路由纯判定（WEBSEARCH→ADVISOR→WORKFLOW→DELEGATE 强触发→OPS 技能卡→GENERAL），OPS 用 `SystemOpsService.hasOpsTrigger()`（skillCards.match 同源）近似
- `SelfIterationController`：feedback / stats / proposals / adopt / reject / iterate / soul/versions / soul/rollback / regression/run / regression/perm-result / regression/cases / skills
- 委托链路接入：`HermesDelegateService.pollAndWriteBack` 终态时 `skillTemplateService.recordUsage(instruction, success)`

## 三、过程中发现并修复的问题

1. **`pid` 只读变量**：PowerShell `$PID` 自动变量不可写 → 改 `$propId`
2. **视图 UNION 排序规则冲突**：`Illegal mix of collations`（四表三种 collation）→ 视图列统一 `CONVERT(... USING utf8mb4) COLLATE utf8mb4_0900_ai_ci`
3. **MySQL 无 TRY_CAST** → `CAST(caller_id AS UNSIGNED)`
4. **mvn 增量编译残留 ECJ 坏 class**：IDE(ECJ) 在 target/classes 留下 `Unresolved compilation problem` 的 class，mvn 增量编译跳过重编打进 jar → 运行时 `java.lang.Error`（AuditChainController 缺 LoginUser import；D6 的 DocComplianceService List import 同根因）→ `mvn clean package` 根治，后续构建一律 clean
5. **审计链视图无 id 列**：ORDER BY id 报 Unknown column → 仅按 create_time DESC
6. **越权 HTTP 200 语义**：GlobalExceptionHandler 的 AccessDenied/Authentication handler 返回 `R<Void>`（HTTP 200 + body 403/401）→ 改 `ResponseEntity` 输出真实 HTTP 状态码（越权拦截可在 HTTP 语义层被外部系统识别）
7. **@PreAuthorize 时序**：参数校验（HandlerMethodArgumentResolver）先于方法级权限（AOP）——空 body 请求先被 400 拦截不触发 403 → 越权探针统一带合法 body
8. **PS5 `$(if...)` 解包 byte[]**：`-Body $(...)` 拿到首个字节 123（ASCII '{'）→ JSON parse error「Number value (123)」→ 改变量传递 `$bodyBytes`
9. **passRate 分母**：含 skip（PERM）用例拉低通过率 → 分母改为 pass+fail
10. **路由期望值校准**：OPS 指令避开 DELEGATE 触发词（帮我处理/汇总/生成报告等）、DELEGATE 指令利用强触发词前置——两类互斥保证 dryRoute 断言确定性
