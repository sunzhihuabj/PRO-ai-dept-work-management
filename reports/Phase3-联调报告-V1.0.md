## 五、披露事项

1. **AI 通道**：当前 Mock 兜底通道（确定性返回），商用通道界面配置后启用；涉及 LLM 的能力（AGT-01/03/06/07/09）以契约结构完整性验证，真实模型效果待通道接入后复测（见 AI 效果达标报告 §4.2）
2. **确定性引擎优先**：AGT-02/11/12/13/16/17/19/21/22/23/25/26 等 12 个能力点核心产出为确定性计算/SQL/模板拼接，数字 100% 来自数据库直取（V2 Never 红线"禁止编造"落地）
3. **钉钉集成**：企业凭证与审批回调验签密钥 AES-256-GCM 加密落库、永不回显；真实钉钉免登 API 链路已按官方接口实现（access_token → oauth2/user），待企业应用凭证配置后切换；dev-mode 沙箱仅限本地联调（默认关闭）
4. **Ask 级状态机口径披露**：pending_confirm 为"执行完成后等待采纳"（草稿已产出），钉钉审批回调 agree 等效确认采纳；回调早于任务执行完成时等待重试（5s）
5. **AGT-10 预留**：规划未明确语义，编号保留（见 AI 效果达标报告 §4.3）
6. **冒烟数据残留**：UAT 环境含 T-213 迁移数据与各期冒烟数据（如 cost_ledger SMOKE_T307 来源记录、repair_ticket UAT 工单），不影响功能验证；生产部署使用 01_schema.sql 全新建库
7. **前端技术债**：AI 通道编辑对话框的 apiKeyHint 提示依赖后端未实现字段（显示为空）；ChatBI 无独立前端页（Agent 工作台可提交 AGT-25 任务），两者纳入 Phase 4 移动端优化
