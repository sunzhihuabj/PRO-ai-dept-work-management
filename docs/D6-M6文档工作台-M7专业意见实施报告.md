## 一、交付范围

### M6 文档工作台（AI 文档草稿全生命周期）

**后端**
- `ai_doc_draft` 表（database/15_ai_doc_advisor.sql）：doc_no 唯一、title/content_md/status(DRAFT/REVIEW/APPROVED)/version/create_by/update_by
- `AiDocDraft` 实体 + `AiDocDraftMapper`
- `DocDraftService`：create（`CodeEngineService.nextCode("DOC", null)` 编号 + 版本 1 + DRAFT）/ update（版本 +1）/ submitReview（DRAFT→REVIEW）/ approve（REVIEW→APPROVED）/ list(status, limit)/ get
- `DocComplianceService`：check(docId, userId) → 文档标题+首段探针 → kb 混合检索 Top-4 → LLM JSON 契约 `{conclusion, items:[{section, risk, basis, suggestion}]}` → 只读风险清单（铁律三：不落库批注，修改走人工）
- `DocDraftController`：`/v1/ai/docs` CRUD + `/{id}/submit-review` + `/{id}/approve` + `/{id}/compliance-check`
- 编码规则：`sys_code_rule` 新增 DOC（`DOC-{yyyyMMdd}-{seq:4}`），seq 行由 CodeEngineService 自动建

**前端**
- `DocWorkbench.vue`：状态过滤 + 草稿列表 + 详情抽屉（预览/编辑切换、合规风险清单 el-table、送审、审核通过）
- `AiWorkspace.vue` 左侧栏新增「文档」tab（懒加载 DocWorkbench）
- `api/aiws.ts`：AiDocDraft 类型 + 7 个文档 API

### M7 专业意见（AGT-28）

- `sys_capability` 新增 AGT-28（category=ADVISOR，allowed_identities=EXPERT,WORKER,ASSISTANT，is_never=0）+ `agent_capability_policy` autonomy_level=2（自动级）
- `AdvisorHandler`（AGT-28）：指令 → kbService.search(instruction, 5) → LLM JSON 契约 `{opinion, confidence, citations:[{ref, quote}]}` → citations 回链 documentTitle/documentId/chunkIndex → `DecisionAdviceService.createAdvisorAdvice`（sourceId=|hash|，needReview → requires_approval=1 + riskLevel=HIGH）；REVIEW_THRESHOLD=0.85，requireConfirm()=false

- Hermes 技能卡 `dept-doc-reviewer`（文档合规员：doc.draft.list → doc.compliance.check → 审核报告，只读铁律）

## 三、过程中发现并修复的问题

1. **DOC 编码规则缺失**：`nextCode("DOC", null)` 报「编码规则不存在或已停用: DOC」→ 补 `sys_code_rule` DOC 规则（对齐 CONV 模式 `{yyyyMMdd}-{seq:4}`）；seq 行由 `codeSeqTxService.nextSeq` 自动创建，无需手工插
2. **AGT-28 身份白名单误写**：`allowed_identities='USER,AGENT'` 不是合法身份码（系统三身份=EXPERT/WORKER/ASSISTANT）→ TaskExecutor 权限校验 fail-closed 升级人工（escalated）→ 修正为 `EXPERT,WORKER,ASSISTANT` 并同步迁移脚本
3. **kb 向量检索全通道失败**：192.168.1.211 LM Studio 不可达 → embed 链 moda(400)/NVIDIA(404)/LM(connect timeout) 全失败 → 启用 MOCK 通道兜底（priority=990 末位，kb_chunk 库内向量本就是 mock-embedding-64，索引/查询一致性成立，混合检索关键词通道同时兜底）
4. **DocComplianceService 缺 `import java.util.List`**：IDE(ECJ) 增量编译产物带病运行 → 运行时 `Unresolved compilation problem: List cannot be resolved` → 补 import + mvn 重打包部署

## 四、已知项（归入 D7 收尾）

- **网关通道降级链耗时**：moda 触发 burst rate 限流（429）时，降级链 moda→NVIDIA(read timeout ~3min)→LM(connect timeout) 累计耗时可超过 backend 180s 客户端超时——需优化网关通道级超时（NVIDIA read timeout 收敛到 ~60s、LM connect timeout 收敛到 ~5s），并遵守「限流后等 10 分钟再调」的调用纪律
- web_research_log 结构化落库（M5 提示词 3.3）
- Dashboard 流程健康度卡片（M4 前端入口 2）
- docx 导出
